XENEON TV / WINDOWS

Deux services. Un lanceur Edge.

F1 TV et CANAL+ s’ouvrent dans Microsoft Edge sur l’écran choisi. Le lanceur Windows remplace le lecteur intégré, bloqué par F1 TV.

Télécharger le lanceur Windows

Code source · Instructions détaillées

  1. Enregistrez XeneonTV.exe dans un dossier durable et ouvrez-le par double-clic.
  2. Choisissez le XENEON EDGE dans la liste des écrans.
  3. Utilisez les deux boutons dans le lanceur et connectez-vous directement sur les sites officiels dans Edge.
  4. Dans iCUE, ajoutez un widget Lancer une application / Launch App pointant vers cet exécutable.

Le profil Edge dédié est conservé sur ce PC. Une première connexion aux deux services est nécessaire ; les services peuvent ensuite demander une nouvelle authentification. Aucun PowerShell ni serveur local à lancer.

Le XENEON EDGE doit afficher le bureau Windows pour montrer la fenêtre Edge. Le lanceur n’intègre pas Edge au tableau de widgets iCUE. Selon votre configuration, quittez l’affichage des widgets pour voir la vidéo.

Exécutable non signé. Compilation vérifiée ; placement sur votre écran et lecture vidéo à tester sur votre matériel.
